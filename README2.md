# Rca - CIE 2 ACTIVITY

## About the Project

This repository contains two Machine Learning experiments performed using Python and Jupyter Notebook.

The experiments cover Regression and Classification techniques using real datasets.

## Experiments Included

### Experiment 1: Diabetes Prediction using Logistic Regression

**Objective:**  
To develop a classification model that predicts whether a person has diabetes or not.

**Dataset:**  
Pima Indians Diabetes Dataset

**Dataset Link:**
https://raw.githubusercontent.com/jbrownlee/Datasets/master/pima-indians-diabetes.data.csv

**Algorithm Used:**
- Logistic Regression

**Libraries Used:**
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

**Steps Performed:**
1. Import required libraries.
2. Load the diabetes dataset.
3. Perform data inspection.
4. Check missing values and duplicate records.
5. Handle zero values using median.
6. Perform Exploratory Data Analysis (EDA).
7. Split data into training and testing sets.
8. Apply StandardScaler.
9. Train the Logistic Regression model.
10. Evaluate the model using:
    - Accuracy
    - Precision
    - Recall
    - Confusion Matrix

### Experiment 2: Diabetes Dataset Analysis using Random Forest Regression

**Objective:**  
To perform data analysis and develop a regression model using the Diabetes dataset.

**Dataset:**  
Scikit-learn Diabetes Dataset

**Algorithm Used:**
- Random Forest Regressor
- Dummy Regressor (Baseline Model)

**Libraries Used:**
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

**Steps Performed:**
1. Import required libraries.
2. Load the Diabetes dataset.
3. Perform data inspection.
4. Perform Exploratory Data Analysis (EDA).
5. Analyze correlation between features.
6. Visualize data using plots.
7. Split data into training and testing sets.
8. Train the Random Forest Regression model.
9. Compare the model with a Dummy Regressor.
10. Evaluate the model using:
    - MAE
    - MSE
    - RMSE
    - R² Score
11. Visualize actual vs predicted values.
12. Display feature importance.
